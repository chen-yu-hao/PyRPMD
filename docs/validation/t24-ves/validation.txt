T24 VES validation evidence (2026-11-03)
======================================

Scope
-----
All models are synthetic, in atomic units, with beta = 1 hartree^-1 and P = 1
for the MD checks. No molecular, bead, timestep, basis-resolution or general
physical convergence is claimed. Production FESResult.physical_converged stays
false. The stochastic optimizer checks and actual MD checks are separate.

Models on [-1.5,1.5]^D
---------------------
1D: F(x) = (x^2 - 1)^2 + 0.2*x.
2D: F(x,y) = (x^2 + 1.4*y^2)/2 + 0.35*x*y + 0.2*x - 0.1*y.
The 2D model includes an explicit mixed term. Unobserved Cartesian directions
in the single-atom MD model have independent harmonic confinement.

References are Gauss-Legendre integrals of probability within each histogram
bin, divided by its volume. The error is computed in the same gauge as the
MBAR estimate. Order-8 versus order-5 quadrature differences are recorded in
reference.json. Umbrella configurations are independent continuous rejection
draws from each exact umbrella ensemble, followed by the existing PyRPMD
reconstruct_fes/MBAR implementation and 24 bootstrap draws. They are not draws
from a discretized grid.

Stochastic optimization checks
------------------------------
Six independently optimized VES histories per dimension/target; each uses
300 iterations x 64 actual stochastic observations = 19,200 observations.
At every coefficient block, exact continuous rejection sampling generates
configurations under the current VES bias. A grid plus a rigorous derivative
bound supplies the rejection envelope; the samples themselves are continuous.
Samples pass through VESBias.observe. No true moments or true coefficients are
injected. Learning rate = 3 hartree, gamma = 4, target update every 10 optimizer
iterations, quadrature order = 32, Legendre degrees [4] or [2,2].

Fixed regression criteria were RMSE below 0.1 kBT, at least fivefold improvement
over a zero-bias estimate, and a 99% simultaneous Bonferroni Student-t band
using five degrees of freedom (six independent histories). The wider finite-
replica band cannot conceal a failure to learn because of the separate RMSE
and improvement requirements. Seeds were not changed during tuning.

1D uniform             0.009920572      3.239086          1.269801
1D well_tempered       0.008851482      3.032068          1.412825

All RMSE values are in hartree (= kBT for these toy models). There is support
in every bin; the gauge bin is excluded from standardized-error comparisons,
leaving 19/20 bins in 1D and 99/100 in 2D. The final RMSE is 0.53--1.20% of the
zero-bias error. The earlier 200-iteration/four-history pilot, including its
large near-gauge standardized error in 2D, is retained in reference.json.

Actual public-workflow MD checks
-------------------------------
Both cases use the public runner, six independent replicas, 1,000 equilibration
steps and 30,000 production steps per replica, dt = 0.04 atomic time units,
PILE-L centroid friction = 1 atomic frequency unit, VES learning rate = 1
hartree, pace = 100, walls = 20 hartree/bohr^2. The bias is frozen at production
step 10,000; 1,000 further steps are discarded for fixed-bias relaxation. Each
replica retains 3,800 frozen samples at interval 5. Reweighting uses beta*V,
including the walls, and reports the common supported region.

Model/target           VES-exact RMSE   Max replica SEM   VES-MBAR max combined SEM
1D uniform             0.098103681      2.414758          1.607420
2D well_tempered       0.127165007      2.286214          2.173162

The 1D comparison uses all 12 bins (11 after excluding the gauge). The 2D
comparison uses 62/64 bins after excluding one unsupported bin and the gauge.
Exact finished-run resume and saved-state reanalysis reproduce the FES arrays
bit for bit for both cases. This is separate from the injected-interruption
unit tests in tests/test_ves_workflow.py.

Supplement: explicit saved-state recomputation
---------------------------------------------
The original driver called analyze_run(output) without recompute=True. Its
default reads the already-written result; that call alone did not establish
explicit recomputation. After the MD campaigns and completed-run resume checks,
both existing run directories were therefore checked again with
analyze_run(output, recompute=True), using their saved samples and optimizer
state. No MD trajectory was rerun.

Before each call, free_energy, mask, uncertainty and every edges array were
copied. Every array after explicit recomputation was elementwise and bytewise
identical, including dtype and NaN locations. Both method fields remained ves,
and converged and physical_converged remained false. In this check the entire
fes.npz archive SHA256 also remained unchanged for each case. The clean output
and per-array/archive hashes are in explicit-recompute.log, with corresponding
provenance added to molecular_dynamics.json. The original MD source commit and
SHA256 fields were preserved without alteration.

The driver now explicitly passes recompute=True and its adjacent comment says
so. This is a validation-only correction; it changes no sampling or estimator
algorithm. The completed check preserves the existing MD provenance and
records the supplemental verification separately.

Minimal reproducible comparison command (after creating the MD runs above):

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python - <<'PY'
from pathlib import Path
import numpy as np
from pyrpmd.analysis.fes_result import FESResult
from pyrpmd.runner import analyze_run

def arrays(result):
    return {"free_energy": result.free_energy.copy(),
            "mask": result.mask.copy(),
            "uncertainty": result.uncertainty.copy(),
            **{f"edges_{axis}": edge.copy()
               for axis, edge in enumerate(result.edges)}}

for name in ("1d-uniform", "2d-well_tempered"):
    output = Path("../t24-md-production") / name
    before = arrays(FESResult.read(output))
    summary = analyze_run(output, recompute=True)
    after = arrays(FESResult.read(output))
    assert before.keys() == after.keys()
    for key in before:
        np.testing.assert_array_equal(before[key], after[key])
        assert before[key].dtype == after[key].dtype
        assert before[key].tobytes() == after[key].tobytes()
    assert summary["method"] == "ves"
    assert summary["converged"] is False
    assert summary["physical_converged"] is False
    print(name, "explicit recompute: all arrays byte-identical")
PY
