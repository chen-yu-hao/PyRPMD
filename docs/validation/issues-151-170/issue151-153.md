Base: `f410b97807d99d429ab1b63c6b1c7ff93b424b5c`.

Issue 151's boundary, log-weight, ESS and frozen-production gates are already
on main. The focused baseline passed 189 tests plus 5 subtests. This change

## Follow-up behavior

Rate-coordinate umbrella CVs now reject the far branch in Python and both
native descriptor interfaces before it contributes a committed sample.
The ordinary diagnostic coordinate remains available on either branch.
Initialization line search rejects far-branch trials; a completed invalid
checkpoint is rejected before its samples are accepted. Failure records keep
the last committed state and Python attempted-branch surface values.

Independent, shared, multiple, asynchronous and MPI walker failures retain
structured records. Only durable completion of that history marks its record
superseded; original failure evidence remains on disk.

Set `[adaptive_umbrella] continuation = true` to seed each new pilot window
from its nearest completed neighbor, then start independently seeded replicas
with full equilibration. Frozen production starts from the corresponding
final-pilot coordinates and discards every pilot sample. Coordinate-source
manifests are part of checkpoint identity. Failed frozen-production support
produces `production-refinement.json` with suggestions for a **new** run; the
frozen plan and readiness are unchanged.

## Optional diagnostics

Run from a source checkout:

```sh
python -m benchmarks.h3.rate_pmf_comparison RUN --xi-star 1.0 --output NEW/comparison.json
python -m benchmarks.h3.stability_ladder INPUT --output NEW/ladder --factors .1 .3 1 --production-steps 100 300 1000
```

The comparison reads `umbrella/fes.h5` without changing `rate_pmf.json`,
reports MBAR/WHAM bin and Gaussian-UI grid sensitivity, and never emits a rate.
The ladder starts independent histories in fresh stage directories, checks
every expected history, and stops on failure. All configured freeze and
relaxation phases must fit the requested budgets. The strongest-bias dt/2
stage preserves physical durations and deposition cadence. The optional
`sampling.monitor_pair_distances` records each accepted full step, using
single-step native blocks; this deliberately costs throughput and is intended
for short preflight diagnostics. It does not observe rejected internal force
substeps. Shared/distributed monitoring is explicitly unsupported.

## Evidence and limits

Direct archived 200 K checkpoints confirm US replica 0 and AUS replica 3 are
on the far branch: denominators -5553.379233 and -3468.378781 bohr, respectively.
Only final coordinates survived; the exact crossing step cannot be recovered.
Both archived anomalies occurred in Python propagation despite native input
settings. Endpoint Kish ESS alone does not reveal global weight collapse.

Six archived US/AUS cases and five saved H3 references support retaining the
2/2/20 gates. Four collapsed archives fail global ESS and two fail displacement;
all five references pass these weight/stream gates. Passing these gates does
not establish all scientific acceptance criteria. Time-correlation corrections
to endpoint contributions are diagnostic pending independent calibration.

Local real-BKMP2 short workflows passed FES, rate umbrellas, constrained parent,
paired recrossing, dRPMD and exact restart checks. The dRPMD comparison records
10275 native steps and zero Python collision steps. All these tests are
implementation checks, not converged physical rates. Low-temperature sampling
improvement and pilot-pass/production-fail frequency remain empirical acceptance
work; no improvement claim is made from short tests. cn53 validation is pending.
