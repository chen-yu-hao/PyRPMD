# Complete-cohort preparation and RDF figure helper

This offline supplement is ready; the original eight-chain campaign is still
running when this method bundle is sealed. No real partial-cohort diffusion or
RDF estimate was used to develop it. It leaves the frozen sampler, protocol,
transport figure helper, and all existing evidence bundles unchanged.

After the original complete-cohort analysis has finished, run from the repository:

```sh
python benchmarks/water/plot_preparation_diagnostics.py COMPLETE_ANALYSIS_DIRECTORY \
  --protocol docs/validation/literature-convergence-2026-11-01/water/protocol.json \
  --output NEW_FIGURE_DIRECTORY
```

The helper reuses the frozen complete-cohort loader, including all eight unique
seed identities, all registered segments, input hashes, and the original
independent-chain uncertainty checks. Its additional checks require every scalar
window observation and an identical finite radial grid for every RDF.

The scalar figure and CSV retain all 32 seed/observable combinations for the
original potential-energy, momentum-temperature, O–H-length and H–O–H-angle
screens. Thresholds and the fixed 50–75 ps / 75–100 ps windows come from the
original protocol. Passing a scalar screen does not certify equilibrium.

The RDF figure and CSV retain every radial bin for both windows and every seed,
plus paired late-minus-early differences. Curves receive equal seed weight.
Bands use the sample standard deviation of eight chain means divided by sqrt(8),
multiplied by the 97.5% Student-t quantile with seven degrees of freedom. The
difference band uses the eight **paired differences**, so a common chain offset
cancels. These are nominal pointwise intervals; they are not simultaneous bounds
or an equivalence test. No new RDF threshold, equilibrium gate, diffusion claim,
or paper comparison is introduced.

The four small synthetic cases exercise correlated-offset cancellation in the
plotted paired statistics, missing scalar-window observations, incomparable
radial grids and nonfinite RDFs. The first run retained an erroneous fixture
aliasing one radius array across all seeds; its failure and correction are
recorded. The final four cases pass. Initial and final counts are not additive.
Both synthetic figures were visually inspected; a footer overlap was corrected
before sealing. Synthetic figures/data stay outside this publication bundle and
are explicitly marked as synthetic when regenerated by the test.

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENMM_CPU_THREADS=1 \
python -m pytest -q tests/test_water_preparation_plot.py
```

This test imports the previously frozen synthetic fixture from
`tests/test_water_native_campaign_plot.py`; that existing test file must be
present. No historical raw checkpoint or OpenMM simulation is needed by these
new cases. `publication-inventory.json` lists the sealed source, test and evidence
files. All long preparation, time-step-control and quantum launches remain
unstarted and require the later whole-cohort decision.
