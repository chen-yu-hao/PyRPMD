# Isotopologue source index for a later campaign

**No new benchmark target is accepted by this index.** The source records separate the reaction identity, readable numerical evidence, document version, and the parameters still needing verification. They do not modify the frozen H3 campaign or initiate another simulation.

The two ACS DOIs describe different reactions. [The 2012 publisher record](https://pubs.acs.org/doi/10.1021/jz201702q) identifies **Mu + H2 → MuH + H**. [The 2014 publisher record](https://pubs.acs.org/doi/10.1021/jz502216g) identifies **D + HMu → DMu + H**, the Mu-transfer stress test. The 2014 author manuscript separately discusses the H-abstraction exit channel. Keeping the incoming atom, transferred atom and product channel explicit is necessary before selecting any dividing surface or benchmark target.

`source-index.json` records links to the original publisher records and two readable author uploads linked from [Yury Suleimanov's own profile](https://cyi.academia.edu/YurySuleimanov). The2013 document is visibly a publisher proof, and the 2014 document is an author manuscript. Their status is retained; neither is silently relabelled a verified final PDF. Selected table values are indexed to locate subsequent checks, not added to the executable reference registry.

Before a new preregistered calculation, obtain the missing mass and propagation details, resolve the 2013 classical-rate/version discrepancy and suspect table exponent, confirm the 2014 table units, and establish a byte-pinned PES implementation. Then register the reaction-specific numerical target, convergence controls and stopping rules without reference to any new computed point estimate.

The full articles are available only through their source links. This directory contains a compact factual index and no copied article or simulation output.
