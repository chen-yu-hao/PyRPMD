# PyRPMD 0.2.0

0.2 extends the merged native propagation core with selectable integration,
multi-path reaction studies, enhanced sampling and versioned restart integrity.
It keeps the default Cayley map and the PES v1 ABI.

## Added

- **Integrators:** Cayley BCB, exact normal-mode BAB and full-ring velocity
  Verlet in both native block interfaces and the NumPy reference. Native
  centroid RATTLE, static biases, fragment projections and continuous Andersen
  sampling preserve the selection. Verlet checks its free-ring stability
  boundary. Low-level PILE-L sampling supports matching BCOCB/BAOAB methods.
- **Reaction networks:** explicit entrances, non-equivalent TS geometries,
  channels and PES inheritance. Each path runs complete PMF, constrained
  parents and paired recrossing children, with deterministic IDs, independent
  normalization and resumable completion. The supported output is a separate
  rate matrix; overlapping surfaces are not summed.
- **Adaptive umbrellas:** actual MBAR overlap and effective-sample diagnostics
  drive midpoint insertion and longer pilots in 1D/2D. A committed, frozen
  window set starts independent production. The standard rate PMF retains its
  rate-flux measure. Budget exhaustion is an explicit failure.
- **Metadynamics:** standard/WT, 1D/2D CVs, smooth periodic Gaussian kernels,
  full ring Jacobians, independent replicas, atomic hill/state/RNG checkpoints,
  and masked finite-time bias FES exports and reanalysis.
- **Portable state:** a v2 NPZ envelope verifies array inventory, shape, dtype
  and SHA256 before resume. No pickle/object arrays. Atomic replacement and
  legacy reads are covered by fault-injection tests. The `checkpoint` CLI
  verifies files without displaying state values.
- **Public API:** `pyrpmd.run`, `prepare`, `resume_run`, `analyze_run`; strict
  task/options validation; documented interface and independent schema/ABI
  versions.

## Compatibility fixes

Run manifest v2 excludes only execution block/backend tuning from scientific
identity. Existing worker/output exclusions remain. Old manifests are migrated
after checking their saved input and file hashes. Changing a method, timestep,
PES, temperature, bead count or bias remains a different scientific run.

Both native failure contracts remain intact: whole-block rollback for
`propagate`, accepted-prefix reporting for `propagate_block`. Automatic native
fallback checks capabilities; an old extension cannot silently substitute
Cayley for another requested map. Rebuild the extension after source updates.

## Distribution and verification

Build a source distribution and a wheel with:

```bash
python -m pip install build
python -m build
```

The source archive includes native sources/headers, examples, tests, method
documentation and existing real-BKMP2 benchmark harnesses. Native wheels are
specific to their Python ABI and build platform; a locally built Linux wheel
is not a portable manylinux wheel or a macOS/Windows binary. Installing the
sdist requires a C++17 compiler, or `PYRPMD_NO_NATIVE=1` for the reference path.
MPI/ASE/Torch adapters keep their separate optional dependencies. Building
artifacts does not imply a PyPI upload.

Release verification covers independent harmonic/normal-mode references,
time reversal and second-order convergence, native/Python block consistency,
RATTLE and RNG ordering, actual multi-path PMF/children, pilot/production
separation, metadynamics deposition-boundary failures, corruption rejection,
legacy manifest migration and package installation outside the checkout.
The existing real-BKMP2 and MPI workflows remain additional regression gates.
Test reports and built artifacts identify their exact source commit in CI.

## Scope of the new methods

The native exact-normal-mode kernel is `O(P²N)`; it favors dependency-free
correctness over FFT-optimal scaling. Adaptive sampling currently refines a
specified domain with fixed stiffness. Metadynamics directly sums accumulated
hills and produces an asymptotic-form finite-time estimate; it does not provide
shared-walker histories, time-dependent reweighting or infrequent-meta kinetics.
Network channel labels do not establish disjoint product basins or transitions
between PESs. None of these additions certifies chemical rate/FES convergence.
